# apex_speedometer 3.2

Modelo APEX da referência, com vidro, marcadores curvos, RPM 0–9 e animações.

Requer `velo_core` 3.0. Mantenha o nome da pasta, inicie `ensure velo_core` e depois `ensure apex_speedometer`. Selecione APEX em `/editvelo`. Não execute a versão monolítica antiga junto desta.

Este recurso fornece o desenho; os dados e o editor vêm do core.
