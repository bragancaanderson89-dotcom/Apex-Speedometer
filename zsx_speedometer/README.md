# zsx_speedometer 3.2

Requer `velo_core` 3.0. Mantenha o nome da pasta, inicie `ensure velo_core` e depois `ensure zsx_speedometer`. Selecione ZSX em `/editvelo`.

Substitui a versão anterior do recurso ao instalar a integração. Não execute o painel antigo ao mesmo tempo. Este modelo recebe a mesma telemetria, editor e ignição do APEX.
